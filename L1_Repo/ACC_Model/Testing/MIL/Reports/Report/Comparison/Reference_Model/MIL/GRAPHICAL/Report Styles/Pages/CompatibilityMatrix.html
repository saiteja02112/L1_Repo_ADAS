Testing techniques
Support value tolerance for expected results
Support time tolerance for expected results Time tolerance management for GEEDS Reactive Systems test template is represented in a different way in both "GEEDS Reactive Systems Testing Results Report" and "Graphical Report for MIL/SIL (HTML)".
Please refer to the userguide for more details.
** Support Flexible input / expected Stimuli - In some templates, you do not need to put an input / expected output value at each time sample. You can put them in a dynamic way and Sentinel will handle.
Ex: your Input1 (Time) = [0, 1, 5 and 10] seconds Input1 (Value) = [ 3.5, 5, 8 and 12] volts, while the sample time of the model is 0.01sec.
